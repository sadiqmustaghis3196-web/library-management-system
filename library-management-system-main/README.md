## ✨ Features

🔹 **Book Management**

- 📝 Add new books with automatic ID generation
- 🔍 Search books by ID with detailed display
- 🔄 Update existing book information
- 🗑️ Delete books with safe record removal
- 📋 Display all books with pagination
